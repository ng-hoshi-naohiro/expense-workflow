## 1. システム概要

複数施設を運営する事業体において、一般経費（施設備品購入・出張交通費・採用関連費）の事前申請から承認までを電子化するワークフローシステム。PC操作に習熟していない申請者・承認者でも直感的に操作できることを最重要視し、生体認証によるワンタップ承認・操作履歴の保存（行政実地指導/会計監査対応）を備える。

**主要利用者ロール**

| ロール | 主な操作 |
|--------|----------|
| 申請者（施設長・本部役職者） | 経費申請、進捗確認、取下げ、再申請 |
| 承認者（本部役職者・上位管理者） | 承認、差戻し、コメント入力 |
| 経理担当者（経理部） | 履歴閲覧、ダッシュボード分析、支払処理 |
| 管理者（管理部門） | マスター管理、監査ログ、システム設定 |

**フロントエンド技術**

| 項目 | 採用技術 |
|------|---------|
| フレームワーク | React 19 |
| 言語 | TypeScript |
| ビルド | Vite |
| ルーター | react-router-dom v7（BrowserRouter） |
| スタイリング | Tailwind CSS |
| アイコン | lucide-react |
| グラフ | recharts |
| 国際化 | i18next / react-i18next |
| 認証（予定） | WebAuthn（Face ID / Touch ID / 指紋） |
| バックエンド連携（予定） | Supabase（Auth / DB / Edge Functions） |

**デザイン基本ルール**

- カラートークン: primary（緑系 #24BD7E）、success（紺系 #1a4480）、warning（橙系 #b85c00）、accent（朱系 #c8472b）、ink（文字色）、ink-soft（補助文字色）、line（罫線）、screen-soft（背景）、paper（ページ背景）
- 角丸: rounded-btn（小）、rounded-card（大）、rounded-full（円形）
- 影: shadow-card（カード）、shadow-modal（モーダル）
- ブレークポイント: モバイル（既定） / md: 768px以上（PC・タブレット）
- フォント: Noto Sans JP（本文）、Noto Serif JP（見出し）、JetBrains Mono（数値・金額）

## 2. 共通レイアウト構成

### 2.1 グローバルヘッダー（Header）

ログイン画面とデバイス登録画面以外の全画面で常時表示。`fixed top-0`、高さ56px（モバイル）/ 64px（PC）。

**PC表示（md以上）**

```
+--------------------------------------------------------------------------+
| [ワークフロー]   [ホーム][申請][承認待ち][履歴]            [鈴○3][User] |
| (ロゴ・ホームへ)  (アクティブはprimary色・bold)        (通知ベル)(ユーザー) |
+--------------------------------------------------------------------------+
```

**モバイル表示（md未満）**

```
+--------------------------------------------------------+
| [≡]      [ワークフロー]                  [鈴○3][User]  |
| ハンバーガー   ロゴ                       通知   ユーザー |
+--------------------------------------------------------+
```

ハンバーガータップ時に全画面ドロワー（ホーム/申請/承認待ち/履歴/ダッシュボード/設定）を表示。

**通知ドロップダウン（ベルタップ時）**

```
+----------------------------------------+
| 通知                  [すべて見る]     |
+----------------------------------------+
| ● 承認依頼が届きました              ●  |  ← 未読は左に色付きドット
|   田中さんから申請が届いています       |
|   2026-05-07                           |
+----------------------------------------+
| ● 承認結果のお知らせ                   |
|   ...                                  |
+----------------------------------------+
| (最大4件、それ以上は[すべて見る]へ)    |
+----------------------------------------+
```

**ユーザーメニュー（Userアイコンタップ時）**

```
+------------------------+
| 田中 太郎              |
| tanaka@example.com     |
+------------------------+
| [⚙] 設定               |  → /settings
| [→] ログアウト         |  → /login（accent色）
+------------------------+
```

### 2.2 ボトムナビゲーション（BottomNav）

**モバイル専用**（mdまで表示、PCでは非表示）。ログイン/デバイス登録では非表示。`fixed bottom-0`、高さ64px。

```
+--------------------------------------------------------+
| [ホーム]  [承認○3]   ┌─[+]─┐    [履歴]   [設定]       |
|   ホーム   承認  (FAB) 申請  (FAB)  履歴    設定        |
+--------------------------------------------------------+
```

中央の「申請」ボタンはFloatingActionButton風（accent色の円形・浮き上がり）。承認アイコンに未対応件数のバッジ。

### 2.3 共通モーダル（ConfirmDialog）

申請送信、承認、差戻し、ログアウト、アカウント削除など破壊的・確認を要する操作で使用。

```
       +----------------------------------------+
       | タイトル（例: 申請を送信しますか？）  |
       +----------------------------------------+
       | メッセージ本文                         |
       | （件名・金額など要約を含む）           |
       |                                        |
       +----------------------------------------+
       |               [キャンセル] [確定ボタン]|
       +----------------------------------------+
```

variant: primary（緑）/ danger（朱）/ warning（橙）。背景は半透明オーバーレイ。

### 2.4 ステータスバッジ（StatusBadge）

申請状態を色付きピル形式で表現する共通コンポーネント。

| status | ラベル例 | 配色 |
|--------|----------|------|
| draft | 下書き | グレー（line/ink-soft） |
| pending | 承認待ち | 橙（warning） |
| approved | 承認済 | 緑（primary） |
| rejected | 差戻し | 朱（accent） |

### 5.1 SC-01 ログイン（`/login`）

**目的**: メールアドレスとパスワード、または登録済デバイスでの生体認証によりシステムへログインする。最初に表示される画面。

**レイアウト**

```
+------------------------------------------+
|                                          |
|             [ ワークフロー ]             |
|             一般経費承認システム         |
|                                          |
|  +------------------------------------+  |
|  | [指紋アイコン] 生体認証でログイン  |  |
|  +------------------------------------+  |
|                                          |
|        ────── または ──────              |
|                                          |
|  メールアドレス                          |
|  +------------------------------------+  |
|  | 会社のメールアドレス               |  |
|  +------------------------------------+  |
|                                          |
|  パスワード                              |
|  +----------------------------+ [👁]    |
|  | パスワード                 |        |
|  +----------------------------+         |
|                                          |
|  +------------------------------------+  |
|  |             ログイン               |  |
|  +------------------------------------+  |
|                                          |
|         パスワードを忘れた方             |
|                                          |
+------------------------------------------+
```

**構成要素**

| 要素 | 役割 | 表示条件 |
|------|------|---------|
| ロゴ・タイトル | ブランドアイデンティティ表示 | 常時 |
| 生体認証ボタン | WebAuthn による即時ログイン | 端末が対応している場合のみ |
| 区切り線「または」 | 認証方式の切替を視覚的に分離 | 生体認証ボタン表示時のみ |
| メールアドレス入力 | 必須。type=email | 常時 |
| パスワード入力 + 表示切替アイコン | 必須。表示/非表示トグル | 常時 |
| エラーバナー | バリデーションエラー表示（朱色） | 入力エラー時のみ |
| ログインボタン | パスワード認証実行 | 常時 |
| パスワードを忘れた方 | パスワードリセット導線 | 常時 |

**入力フィールド**

| ラベル | 型 | 必須 | バリデーション | プレースホルダ |
|--------|-----|------|----------------|---------------|
| メールアドレス | email | 〇 | 空欄不可 | 会社のメールアドレス |
| パスワード | password / text | 〇 | 空欄不可 | パスワード |

**状態バリエーション**

| 状態 | 表示 |
|------|------|
| 通常 | フォーム入力可能 |
| ローディング | ボタンが「認証中...」「ログイン中...」、disabled |
| エラー | 上部にエラーバナー表示（メールアドレス未入力／パスワード未入力等） |

**遷移**

| トリガー | 遷移先 |
|----------|--------|
| 生体認証ボタンタップ | 認証成功 → SC-03 ホーム |
| ログインボタンタップ | 認証成功 → SC-02 デバイス登録 |
| パスワードを忘れた方 | （未実装、将来パスワードリセット画面へ） |

### 5.2 SC-02 デバイス登録（`/setup/device`）

**目的**: ログイン後、現在のデバイスを承認用端末として登録し、次回以降の生体認証ログインを可能にする。スキップも可能。

**レイアウト**

```
+------------------------------------------+
|                                          |
|             デバイス登録                 |
|     このデバイスを承認用端末として登録   |
|                                          |
|  +------------------------------------+  |
|  | 登録するメリット                   |  |
|  | [✓] 次回からパスワード入力が不要   |  |
|  | [✓] 生体認証でセキュアなログイン   |  |
|  | [✓] 承認操作もワンタップで完了     |  |
|  +------------------------------------+  |
|                                          |
|  +------------------------------------+  |
|  | 検出されたデバイス                 |  |
|  | [📱] iPhone Safari                 |  |
|  +------------------------------------+  |
|                                          |
|  +------------------------------------+  |
|  | [指紋] このデバイスを登録する      |  |
|  +------------------------------------+  |
|                                          |
|         あとで登録する                   |
|   ※推奨しません。セキュリティと利便性   |
|     が低下します                         |
|                                          |
+------------------------------------------+
```

**登録成功時（success状態）**

```
+------------------------------------------+
|                                          |
|         [✓ 大きなチェックアイコン]       |
|         登録が完了しました               |
|         ホーム画面に移動します...        |
|                                          |
+------------------------------------------+
```

**構成要素**

| 要素 | 役割 |
|------|------|
| メリット説明カード | 登録するメリットを3項目で訴求 |
| デバイス情報カード | userAgent から判別したデバイス名を表示 |
| 登録ボタン | デバイス登録実行（生体認証連携） |
| スキップリンク | 登録せずホームへ |
| 成功フィードバック | 登録完了後1.5秒で自動遷移 |

**状態バリエーション**

| 状態 | 表示 |
|------|------|
| 通常 | 登録ボタン押下可能 |
| 登録中 | ボタン「登録中...」、disabled |
| 成功 | チェックアイコン全画面、1.5秒後にホームへ |
| エラー | 上部にエラーバナー（朱色） |

**遷移**

| トリガー | 遷移先 |
|----------|--------|
| 登録ボタン → 成功 | SC-03 ホーム（自動遷移） |
| あとで登録するボタン | SC-03 ホーム |

| | +----------------+ |  +-----------------------+        |
| | [📄] 前回と同じ... |  +-----------------------+        |
| +--------------------+  | 最近の活動            |        |
| +--------------------+  | ●─ ●─ ●─ ●           |        |
| | 月次推移グラフ      |  | 田中さんが申請しました|        |

**レイアウト（モバイル・1カラム）**: 上記カードを縦に積み重ね、グリッドは2列の統計カードのみ維持。

**構成要素（カード単位）**

| カード | 内容 | 表示条件 |
|--------|------|---------|
| 挨拶ヘッダー | ユーザー名 + 時間帯挨拶 + 今日の日付 | 常時 |

| 月次推移ミニチャート | 棒グラフ（5ヶ月分）+ ダッシュボードへの「詳細」リンク | 常時 |
| 承認待ちアラート | 「N件の承認待ちがあります」（橙色） | currentUser.pendingApprovals > 0 |
| 進行中の申請 | pending/draftの申請を最大3件表示。空時はメッセージ | 常時 |
| 統計カード（2列） | 総申請数 / 総金額 | 常時 |
| 最近の活動 | タイムライン表示（承認/差戻し/申請の3種類アイコン） | activityTimeline存在時 |
| 承認待ち一覧プレビュー | pendingApprovalsを最大2件表示 | pendingApprovals.length > 0 |
| 予算使用状況 | プログレスバー + 使用額/総額 + 残額 | 常時 |

**データ参照**: `currentUser`、`applications`、`pendingApprovals`、`activityTimeline`、`monthlyStats`、`monthlyTrends`、`budgetOverview`

| トリガー | 遷移先 |
